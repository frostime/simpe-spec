# Request: rename-ask

## Background
<!-- Current situation, background information -->
在早期 sspec 开发的时候，我主力使用 copilot，那时候还没有 Vscode Ask User Question 工具。
由于 copilot 是按照轮次计费，为了节省开支，我开发了 sspec ask ，让 Agent 能在单个轮次中和 User 沟通并及时变更方向，避免由于方向失败不得不多轮讨论浪费多余的 Credit 开支。
后来随着开发的继续，我把 @ask 定义为 sspec ask 和 使用 Agent 系统内置的 question-like 工具。

## Problem
<!-- What is not working or missing -->

**此前的审查提到 @ask 的模糊性**
> **建议 H：phase gate 的 @ask 用 `sspec ask` 还是 `question` 工具要更明确**
> 来自 wip/analysis-report.md —— L379

我个人认为本质是 @ask 和 sspec-ask 字符串类似，容易让 Agent 迷惑

## Initial Direction
<!-- Your rough idea or preferred direction — details are fine but not required.
This becomes the starting point for the change's spec.md Section A/B. -->

我在思考，把 @ask 改成 @align 是否会更加契合当前的设计，这里的的理念是：

- **目标**：Agent 要对齐用户的想法
- 方案：发送请求
- 具体手段
  - Agent 中是否有内置的 question 工具? -> HasQueTool
  - If not -> `sspec ask` + user feedback loop
  - 需要问的问题的复杂性 || 是否是需要留存的关键问题
    - If so -> `sspec ask` + user feedback loop
    - If light align -> Use Question Tool
